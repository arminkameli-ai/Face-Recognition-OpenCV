# 🇬🇧 English

## 📖 About the Project

This project is a real-time face recognition system built with **Python**, **OpenCV**, and the **face_recognition** library.

The program uses a webcam to detect faces and compares them with previously registered face encodings. If a match is found, the person's name is displayed on the screen; otherwise, the face is labeled as **Unknown**.

---

## ✨ Features

- 🎥 Real-time webcam face recognition
- 👤 Recognition of multiple known faces
- 🟥 Face detection with bounding boxes
- 🏷️ Display recognized person's name
- ❓ Unknown face detection
- ⚡ Fast and efficient implementation

---

## 🛠 Technologies Used

- Python
- OpenCV
- face_recognition
- NumPy

## ▶️ How to Run

Install the required packages:

```bash
pip install -r requirements.txt
```

Run the project:

```bash
python face_recognition.py
```

Press **Q** to close the webcam window.

---

## 📌 Notes

- The project uses sample reference images (`obama.jpg` and `biden.jpg`).
- You can replace these images with your own to recognize different people.
